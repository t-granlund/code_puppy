--- TEST REQUEST ---

I need to implement a secure user authentication system for a FastAPI application that supports OAuth2 with refresh tokens, rate limiting, and audit logging. The system should handle JWT access tokens (15min expiry) + refresh tokens (7 days), implement rate limiting (5 attempts/minute for login, 100 requests/hour for APIs), log all authentication events to a secure audit trail, store user credentials securely with bcrypt hashing, and support role-based access control (admin, user, read-only roles).

The existing codebase has:
- Basic FastAPI setup in src/main.py
- PostgreSQL connection via SQLAlchemy in src/database.py  
- No authentication layer yet

I need:
1. Security review of the proposed design (identify potential vulnerabilities like token theft, replay attacks, timing attacks)
2. Code review of the existing database layer (check for SQL injection risks, connection pooling issues, and security best practices)
3. Test strategy for the auth flows (unit tests for token generation, integration tests for login/logout/refresh flows)
4. Implementation of the full auth system (models, routes, security utilities)
5. Documentation for the API endpoints (OpenAPI/Swagger compatible)

Can you guide me through this using the epistemic methodology and OODA loop? Please delegate to specialist agents for security analysis, code review, QA planning, and implementation.

--- END TEST REQUEST ---
