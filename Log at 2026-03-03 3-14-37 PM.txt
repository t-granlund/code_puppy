[03/03/2026, 15:12:11]

[03/03/2026, 15:12:11]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────

[03/03/2026, 15:12:11] ────────────────────────────────────
[03/03/2026, 15:12:11]
[03/03/2026, 15:12:11] Real decorators need to handle any arguments the original function takes:

[03/03/2026, 15:12:11]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────

[03/03/2026, 15:12:12] • *args, **kwargs captures any arguments

[03/03/2026, 15:12:12] Preserving Function Metadata
[03/03/2026, 15:12:12] ────────────────────────────
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] Wait, there's a bug! If you check slow_function.__name__ after decorating, it says "wrapper" not "slow_function". That's annoying! 🐛
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] Fix it with functools.wraps:
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:12] from functools import wraps
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] def timer_decorator(func):
[03/03/2026, 15:12:12]     @wraps(func)
[03/03/2026, 15:12:12]     def wrapper(*args, **kwargs):
[03/03/2026, 15:12:12]         import time
[03/03/2026, 15:12:12]         start = time.time()
[03/03/2026, 15:12:12]         result = func(*args, **kwargs)
[03/03/2026, 15:12:12]         end = time.time()
[03/03/2026, 15:12:12]         print(f"⏱️ {func.__name__} took {end - start:.4f} seconds")
[03/03/2026, 15:12:12]         return result
[03/03/2026, 15:12:12]     return wrapper
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] @timer_decorator
[03/03/2026, 15:12:12] def my_function():
[03/03/2026, 15:12:12]     """This function does stuff."""
[03/03/2026, 15:12:12]     pass
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] print(my_function.__name__)  # my_function (not wrapper!)
[03/03/2026, 15:12:12] print(my_function.__doc__)   # This function does stuff.
[03/03/2026, 15:12:12] ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] @wraps(func) copies over the original function's metadata (name, docstring, etc.) to the wrapper.
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────

[03/03/2026, 15:12:12] Decorators with Arguments
[03/03/2026, 15:12:12] ─────────────────────────
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] Sometimes you want to parameterize your decorator. You need three levels of nesting:
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:12] def repeat_decorator(times):
[03/03/2026, 15:12:12]     """
[03/03/2026, 15:12:12]     A decorator factory - returns a decorator that repeats the function.
[03/03/2026, 15:12:12]     Usage: @repeat(3)
[03/03/2026, 15:12:12]     """
[03/03/2026, 15:12:12]     def decorator(func):
[03/03/2026, 15:12:12]         @wraps(func)
[03/03/2026, 15:12:12]         def wrapper(*args, **kwargs):
[03/03/2026, 15:12:12]             results = []
[03/03/2026, 15:12:12]             for _ in range(times):
[03/03/2026, 15:12:12]                 result = func(*args, **kwargs)
[03/03/2026, 15:12:12]                 results.append(result)
[03/03/2026, 15:12:12]             return results  # Return all results as a list
[03/03/2026, 15:12:12]         return wrapper
[03/03/2026, 15:12:12]     return decorator
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] @repeat_decorator(3)
[03/03/2026, 15:12:12] def roll_dice():
[03/03/2026, 15:12:12]     import random
[03/03/2026, 15:12:12]     return random.randint(1, 6)
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] print(roll_dice())  # e.g., [4, 2, 5]
[03/03/2026, 15:12:12] ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] The pattern is:
[03/03/2026, 15:12:12] • Outer function - accepts decorator arguments (times)
[03/03/2026, 15:12:12] • Middle function - accepts the function being decorated (func)
[03/03/2026, 15:12:12] • Inner function - the actual wrapper that runs on each call
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:12]

[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] You can stack decorators! They apply from bottom to top:

[03/03/2026, 15:12:12]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────

[03/03/2026, 15:12:12]     @wraps(func)

[03/03/2026, 15:12:12]         return f"<b>{func(*args, **kwargs)}</b>"
[03/03/2026, 15:12:12]     return wrapper

[03/03/2026, 15:12:12] def italic(func):
[03/03/2026, 15:12:12]     @wraps(func)
[03/03/2026, 15:12:12]     def wrapper(*args, **kwargs):

[03/03/2026, 15:12:12] @italic
[03/03/2026, 15:12:12] def greet(name):
[03/03/2026, 15:12:12]     return f"Hello, {name}!"
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] print(greet("Tyler"))

[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] Execution order: greet → italic → bold

[03/03/2026, 15:12:12] Class Decorators
[03/03/2026, 15:12:12] ────────────────
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12] Decorators can also be classes! The class needs __call__ method:
[03/03/2026, 15:12:12]
[03/03/2026, 15:12:12]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:12] class CountCalls:
[03/03/2026, 15:12:12]     def __init__(self, func):
[03/03/2026, 15:12:12]         self.func = func
[03/03/2026, 15:12:13]         self.count = 0

[03/03/2026, 15:12:13]
[03/03/2026, 15:12:13] @CountCalls
[03/03/2026, 15:12:13] def say_hi():
[03/03/2026, 15:12:13]     print("Hi there!")
[03/03/2026, 15:12:13]
[03/03/2026, 15:12:13] say_hi()  # 📊 Called 1 times, Hi there!
[03/03/2026, 15:12:13] say_hi()  # 📊 Called 2 times, Hi there!
[03/03/2026, 15:12:13] say_hi()  # 📊 Called 3 times, Hi there!

[03/03/2026, 15:12:13]
[03/03/2026, 15:12:13] This is great for decorators that need to maintain state (like counting calls).

[03/03/2026, 15:12:13] Decorator Classes (Decorating Classes)
[03/03/2026, 15:12:13] ──────────────────────────────────────
[03/03/2026, 15:12:13]
[03/03/2026, 15:12:13] You can also decorators classes themselves:
[03/03/2026, 15:12:13]
[03/03/2026, 15:12:13]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────

[03/03/2026, 15:12:13]

[03/03/2026, 15:12:29]                 new_dct[key] = value
[03/03/2026, 15:12:29]
[03/03/2026, 15:12:29]         # Call the parent's __new__ to actually create the class
[03/03/2026, 15:12:29]         return super().__new__(cls, name, bases, new_dct)
[03/03/2026, 15:12:29]
[03/03/2026, 15:12:29] # Use the metaclass
[03/03/2026, 15:12:29] class MyClass(metaclass=UpperAttrMetaclass):
[03/03/2026, 15:12:29]     my_attr = "hello"
[03/03/2026, 15:12:29]
[03/03/2026, 15:12:29]     def my_method(self):
[03/03/2026, 15:12:29]         return "world"
[03/03/2026, 15:12:29]
[03/03/2026, 15:12:29] # Now everything is uppercase!
[03/03/2026, 15:12:29] print(MyClass.MY_ATTR)    # hello
[03/03/2026, 15:12:29] print(MyClass().MY_METHOD())  # world
[03/03/2026, 15:12:29] # MyClass.my_attr would raise AttributeError!
[03/03/2026, 15:12:29] ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:29]
[03/03/2026, 15:12:29] Note: We override __new__ (not __init__) because we want to modify the class before it's created. The class dictionary is our chance to change things!
[03/03/2026, 15:12:29]

[03/03/2026, 15:12:29] __new__ vs __init__ in Metaclasses
[03/03/2026, 15:12:29] ──────────────────────────────────
[03/03/2026, 15:12:29]
[03/03/2026, 15:12:29] Key difference:
[03/03/2026, 15:12:29]
[03/03/2026, 15:12:29] • `__new__`: Creates and returns the class object. Use this to modify the class before it exists.
[03/03/2026, 15:12:29] • `__init__`: Initializes an already-created class. Use this to add/modify attributes after the class exists.
[03/03/2026, 15:12:29]
[03/03/2026, 15:12:29]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:29] class DebugMetaclass(type):
[03/03/2026, 15:12:29]     def __new__(cls, name, bases, dct):
[03/03/2026, 15:12:29]         print(f"__new__: Creating class '{name}'")
[03/03/2026, 15:12:29]         # We can modify dct here
[03/03/2026, 15:12:29]         return super().__new__(cls, name, bases, dct)
[03/03/2026, 15:12:29]
[03/03/2026, 15:12:29]     def __init__(cls, name, bases, dct):
[03/03/2026, 15:12:29]         print(f"__init__: Initializing class '{name}'")
[03/03/2026, 15:12:29]         # We can modify attrs on the class here
[03/03/2026, 15:12:29]         cls.created_at = "just now"  # Add a timestamp
[03/03/2026, 15:12:29]         super().__init__(name, bases, dct)
[03/03/2026, 15:12:29]
[03/03/2026, 15:12:29] class MyClass(metaclass=DebugMetaclass):
[03/03/2026, 15:12:29]     pass
[03/03/2026, 15:12:29]

[03/03/2026, 15:12:30] Real-World Example 1: Singleton Pattern
[03/03/2026, 15:12:30] ───────────────────────────────────────
[03/03/2026, 15:12:30]
[03/03/2026, 15:12:30] Force a class to have only one instance:
[03/03/2026, 15:12:30]
[03/03/2026, 15:12:30]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:30] class SingletonMeta(type):
[03/03/2026, 15:12:30]     """
[03/03/2026, 15:12:30]     Metaclass that creates a singleton instance.
[03/03/2026, 15:12:30]     """
[03/03/2026, 15:12:30]     _instances = {}
[03/03/2026, 15:12:30]
[03/03/2026, 15:12:30]     def __call__(cls, *args, **kwargs):
[03/03/2026, 15:12:30]         # __call__ is triggered when you do ClassName()
[03/03/2026, 15:12:30]         if cls not in cls._instances:
[03/03/2026, 15:12:30]             cls._instances[cls] = super().__call__(*args, **kwargs)
[03/03/2026, 15:12:30]         return cls._instances[cls]
[03/03/2026, 15:12:30]
[03/03/2026, 15:12:30] class Database(metaclass=SingletonMeta):

[03/03/2026, 15:12:30] Real-World Example 2: Attribute Validation
[03/03/2026, 15:12:30] ──────────────────────────────────────────
[03/03/2026, 15:12:30]
[03/03/2026, 15:12:30] Ensure certain attributes are always the right type:
[03/03/2026, 15:12:30]
[03/03/2026, 15:12:30]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:30] class ValidatedMeta(type):
[03/03/2026, 15:12:30]     def __new__(cls, name, bases, dct):
[03/03/2026, 15:12:30]         # Find validation rules in _fields dictionary
[03/03/2026, 15:12:30]         fields = dct.get('_fields', {})
[03/03/2026, 15:12:30]
[03/03/2026, 15:12:30]         # Create property getters/setters for validated fields
[03/03/2026, 15:12:30]         for field_name, field_type in fields.items():
[03/03/2026, 15:12:30]             private_name = f'_{field_name}'
[03/03/2026, 15:12:30]
[03/03/2026, 15:12:30]             # Getter
[03/03/2026, 15:12:30]             if field_name not in dct:
[03/03/2026, 15:12:30]                 def make_getter(private):
[03/03/2026, 15:12:30]                     def getter(self):
[03/03/2026, 15:12:30]                         return getattr(self, private)
[03/03/2026, 15:12:30]                     return getter
[03/03/2026, 15:12:30]                 dct[field_name] = property(make_getter(private_name))
[03/03/2026, 15:12:30]
[03/03/2026, 15:12:30]             # Set the initial value
[03/03/2026, 15:12:30]             if field_name in dct:
[03/03/2026, 15:12:30]                 initial_value = dct[field_name]
[03/03/2026, 15:12:30]                 if not isinstance(initial_value, field_type):
[03/03/2026, 15:12:30]                     raise TypeError(f"{field_name} must be {field_type}, got {type(initial_value)}")
[03/03/2026, 15:12:30]                 dct[private_name] = initial_value
[03/03/2026, 15:12:30]                 del dct[field_name]
[03/03/2026, 15:12:30]
[03/03/2026, 15:12:30]         return super().__new__(cls, name, bases, dct)
[03/03/2026, 15:12:30]
[03/03/2026, 15:12:30]     def __call__(cls, *args, **kwargs):
[03/03/2026, 15:12:30]         # Add __setattr__ validation at instance creation time
[03/03/2026, 15:12:31]         instance = super().__call__(*args, **kwargs)
[03/03/2026, 15:12:31]         fields = getattr(cls, '_fields', {})
[03/03/2026, 15:12:31]
[03/03/2026, 15:12:31]         original_setattr = instance.__setattr__
[03/03/2026, 15:12:31]
[03/03/2026, 15:12:31]         def validated_setattr(name, value):
[03/03/2026, 15:12:31]             if name in fields and not isinstance(value, fields[name]):
[03/03/2026, 15:12:31]                 raise TypeError(f"{name} must be {fields[name]}, got {type(value)}")
[03/03/2026, 15:12:31]             original_setattr(name, value)
[03/03/2026, 15:12:31]
[03/03/2026, 15:12:31]         instance.__setattr__ = validated_setattr
[03/03/2026, 15:12:31]         return instance
[03/03/2026, 15:12:31]
[03/03/2026, 15:12:31] class User(metaclass=ValidatedMeta):
[03/03/2026, 15:12:31]     _fields = {
[03/03/2026, 15:12:31]         'name': str,
[03/03/2026, 15:12:31]         'age': int,
[03/03/2026, 15:12:31]         'email': str
[03/03/2026, 15:12:31]     }
[03/03/2026, 15:12:31]

[03/03/2026, 15:12:31] Real-World Example 3: Auto-Registering Subclasses
[03/03/2026, 15:12:31] ─────────────────────────────────────────────────
[03/03/2026, 15:12:31]
[03/03/2026, 15:12:31] Great for plugin systems:
[03/03/2026, 15:12:31]
[03/03/2026, 15:12:31]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:31] class PluginRegistry(type):
[03/03/2026, 15:12:31]     """
[03/03/2026, 15:12:31]     Automatically registers all subclasses in a registry.
[03/03/2026, 15:12:31]     """
[03/03/2026, 15:12:31]     _registry = {}
[03/03/2026, 15:12:31]
[03/03/2026, 15:12:31]     def __new__(cls, name, bases, dct):
[03/03/2026, 15:12:31]         new_class = super().__new__(cls, name, bases, dct)
[03/03/2026, 15:12:31]
[03/03/2026, 15:12:31]         # Don't register the base class itself
[03/03/2026, 15:12:31]         if not dct.get('_is_base_plugin', False):
[03/03/2026, 15:12:31]             plugin_name = dct.get('name', name.lower())
[03/03/2026, 15:12:31]             cls._registry[plugin_name] = new_class
[03/03/2026, 15:12:31]
[03/03/2026, 15:12:31]         return new_class
[03/03/2026, 15:12:31]
[03/03/2026, 15:12:31]     @classmethod
[03/03/2026, 15:12:31]     def get_plugin(cls, name):
[03/03/2026, 15:12:31]         return cls._registry.get(name)
[03/03/2026, 15:12:31]
[03/03/2026, 15:12:31]     @classmethod
[03/03/2026, 15:12:31]     def list_plugins(cls):
[03/03/2026, 15:12:31]         return list(cls._registry.keys())
[03/03/2026, 15:12:31]
[03/03/2026, 15:12:31]     @classmethod
[03/03/2026, 15:12:31]     def create_plugin(cls, name, *args, **kwargs):
[03/03/2026, 15:12:31]         plugin_class = cls.get_plugin(name)
[03/03/2026, 15:12:31]         if plugin_class:
[03/03/2026, 15:12:31]             return plugin_class(*args, **kwargs)
[03/03/2026, 15:12:31]         raise ValueError(f"Plugin '{name}' not found")
[03/03/2026, 15:12:31]
[03/03/2026, 15:12:31] class Plugin(metaclass=PluginRegistry):

[03/03/2026, 15:12:31]     def process(self, data):
[03/03/2026, 15:12:31]         raise NotImplementedError

[03/03/2026, 15:12:31]     name = "email"

[03/03/2026, 15:12:31]     def process(self, data):

[03/03/2026, 15:12:32] Metaclass Inheritance
[03/03/2026, 15:12:32] ─────────────────────
[03/03/2026, 15:12:32]
[03/03/2026, 15:12:32] Metaclasses form their own inheritance hierarchy. When you inherit from a class with a metaclass, the metaclass follows:
[03/03/2026, 15:12:32]
[03/03/2026, 15:12:32]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:32] class MetaA(type):
[03/03/2026, 15:12:32]     def __new__(cls, name, bases, dct):
[03/03/2026, 15:12:32]         dct['from_meta_a'] = True
[03/03/2026, 15:12:32]         return super().__new__(cls, name, bases, dct)
[03/03/2026, 15:12:32]
[03/03/2026, 15:12:32] class MetaB(type):
[03/03/2026, 15:12:32]     def __new__(cls, name, bases, dct):
[03/03/2026, 15:12:32]         dct['from_meta_b'] = True
[03/03/2026, 15:12:32]         return super().__new__(cls, name, bases, dct)
[03/03/2026, 15:12:32]
[03/03/2026, 15:12:32] class ClassA(metaclass=MetaA):
[03/03/2026, 15:12:32]     pass
[03/03/2026, 15:12:32]
[03/03/2026, 15:12:32] class ClassB(ClassA):
[03/03/2026, 15:12:32]     pass
[03/03/2026, 15:12:32]
[03/03/2026, 15:12:32] print(ClassA.from_meta_a)  # True
[03/03/2026, 15:12:32] print(ClassB.from_meta_a)  # True! Metaclass inherited
[03/03/2026, 15:12:32] ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:32]
[03/03/2026, 15:12:32] Conflict! What if you inherit from two classes with different metaclasses?
[03/03/2026, 15:12:32]
[03/03/2026, 15:12:32]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:32] class ClassA(metaclass=MetaA):
[03/03/2026, 15:12:32]     pass
[03/03/2026, 15:12:32]
[03/03/2026, 15:12:32] class ClassB(metaclass=MetaB):
[03/03/2026, 15:12:32]     pass
[03/03/2026, 15:12:32]
[03/03/2026, 15:12:32] try:
[03/03/2026, 15:12:32]     class ClassC(ClassA, ClassB):
[03/03/2026, 15:12:32]         pass
[03/03/2026, 15:12:32] except TypeError as e:
[03/03/2026, 15:12:32]     print(e)
[03/03/2026, 15:12:32]     # metaclass conflict: the metaclass of a derived class
[03/03/2026, 15:12:32]     # must be a (non-strict) subclass of the metaclasses of all its bases
[03/03/2026, 15:12:32] ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:32]
[03/03/2026, 15:12:32] Solution: create a metaclass that inherits from both:
[03/03/2026, 15:12:32]
[03/03/2026, 15:12:32]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:12:32] class MetaAB(MetaA, MetaB):
[03/03/2026, 15:12:32]     def __new__(cls, name, bases, dct):
[03/03/2026, 15:12:32]         dct['from_meta_ab'] = True
[03/03/2026, 15:12:32]         return super().__new__(cls, name, bases, dct)
[03/03/2026, 15:12:32]
[03/03/2026, 15:12:32] class ClassC(ClassA, ClassB, metaclass=MetaAB):
[03/03/2026, 15:12:32]     pass
[03/03/2026, 15:12:32]
[03/03/2026, 15:12:32] print(ClassC.from_meta_a)   # True
[03/03/2026, 15:12:32] print(ClassC.from_meta_b)   # True
[03/03/2026, 15:12:32] print(ClassC.from_meta_ab)  # True
[03/03/2026, 15:12:32] ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────

[03/03/2026, 15:12:58] The Heart: The Event Loop
[03/03/2026, 15:12:58] ─────────────────────────
[03/03/2026, 15:12:58]
[03/03/2026, 15:12:58] The event loop is like a traffic controller that switches between tasks:
[03/03/2026, 15:12:58]
[03/03/2026, 15:12:58] Event Loop Flow:
[03/03/2026, 15:12:58] ─────────────────────────────────────────
[03/03/2026, 15:12:58] Task 1: "I need to wait 2 seconds..."
[03/03/2026, 15:12:58]           ↓ (pause, switch)
[03/03/2026, 15:12:58] Task 2: "I need to fetch some data..."
[03/03/2026, 15:12:58]           ↓ (pause, switch)
[03/03/2026, 15:12:58] Task 3: "Let me process something..."
[03/03/2026, 15:12:58]           ↓ (pause, switch)
[03/03/2026, 15:12:58] ...2 seconds later...
[03/03/2026, 15:12:58] Task 1: "I'm done! Here's my result"
[03/03/2026, 15:12:58] Task 2: "I'm done! Here's my result"
[03/03/2026, 15:12:58] Task 3: "I'm done! Here's my result"
[03/03/2026, 15:12:58]
[03/03/2026, 15:12:58] Key point: It's cooperative multitasking - tasks must explicitly await to give control back. Unlike threading, there's no context switching overhead!

[03/03/2026, 15:13:02] The Golden Rule: Never Block the Event Loop! 🚨
[03/03/2026, 15:13:02] ───────────────────────────────────────────────
[03/03/2026, 15:13:02]
[03/03/2026, 15:13:02] This is the most important rule:
[03/03/2026, 15:13:02]
[03/03/2026, 15:13:02]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:13:02] import asyncio
[03/03/2026, 15:13:02] import time  # ⚠️ DANGER!
[03/03/2026, 15:13:02]
[03/03/2026, 15:13:02] async def blocking_code():
[03/03/2026, 15:13:02]     print("Starting (this will BLOCK everything!)")
[03/03/2026, 15:13:02]
[03/03/2026, 15:13:03]     # 🚨 WRONG! This blocks the entire event loop!
[03/03/2026, 15:13:03]     time.sleep(3)
[03/03/2026, 15:13:03]
[03/03/2026, 15:13:03]     print("Done")
[03/03/2026, 15:13:03]     return "Data"
[03/03/2026, 15:13:03]
[03/03/2026, 15:13:03] async def non_blocking_code():
[03/03/2026, 15:13:03]     print("Starting...")
[03/03/2026, 15:13:03]     await asyncio.sleep(3)  # ✅ CORRECT! Non-blocking
[03/03/2026, 15:13:03]     print("Done")

[03/03/2026, 15:13:03] Blocking operations to avoid in async code:
[03/03/2026, 15:13:03] • ❌ time.sleep() → use asyncio.sleep()
[03/03/2026, 15:13:03] • ❌ requests.get() → use aiohttp or httpx
[03/03/2026, 15:13:03] • ❌ Heavy CPU loops → use loop.run_in_executor() or multiprocessing
[03/03/2026, 15:13:03] • ❌ Blocking file I/O (usually OK, but consider aiofiles for large files)

[03/03/2026, 15:13:03]
[03/03/2026, 15:13:04] ┌─────────────────┬───────────────────────────┬─────────────────────────────────────────────────────────┬─────────────────────────────────────┐
[03/03/2026, 15:13:04] │ Approach        │ Best For                  │ Example                                                 │ Python Limit                        │
[03/03/2026, 15:13:04] ├─────────────────┼───────────────────────────┼─────────────────────────────────────────────────────────┼─────────────────────────────────────┤
[03/03/2026, 15:13:04] │ Async/Await     │ I/O-bound concurrent work │ Web scraping, API calls, database queries (async DB)    │ Single-threaded, no CPU parallelism │
[03/03/2026, 15:13:04] │ Threading       │ Some I/O + quick CPU ops  │ Limited concurrent I/O when async libraries unavailable │ GIL limits CPU parallelism          │
[03/03/2026, 15:13:04] │ Multiprocessing │ CPU-bound work            │ Image processing, data crunching, number crunching      │ True parallelism (bypasses GIL)     │

[03/03/2026, 15:13:05] Key Takeaways 🎓
[03/03/2026, 15:13:05] ────────────────
[03/03/2026, 15:13:05]
[03/03/2026, 15:13:05] • Async is for I/O-bound work - waiting for network, disk, databases
[03/03/2026, 15:13:05] • The event loop switches between paused tasks automatically
[03/03/2026, 15:13:05] • `await` pauses your coroutine without blocking the entire program
[03/03/2026, 15:13:05] • `asyncio.create_task()` starts work in the background
[03/03/2026, 15:13:05] • `asyncio.gather()` waits for multiple tasks and collects results
[03/03/2026, 15:13:05] • Never block the loop! ❌ No time.sleep(), no requests.get()
[03/03/2026, 15:13:05] • Use async libraries designed for the event loop (aiohttp, httpx, etc.)
[03/03/2026, 15:13:05] • For CPU work, use run_in_executor() or multiprocessing instead
[03/03/2026, 15:13:05]
[03/03/2026, 15:13:05] Async/await makes concurrent code fast and manageable - once you get the hang of the event loop, you'll be slinging concurrent code like a pro! 🚀

[03/03/2026, 15:14:10] ───────────────────────────────────────
[03/03/2026, 15:14:10]
[03/03/2026, 15:14:10] Writing full classes is verbose. Python's contextlib module has your back!
[03/03/2026, 15:14:10]
[03/03/2026, 15:14:10]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:14:11] from contextlib import contextmanager
[03/03/2026, 15:14:11]
[03/03/2026, 15:14:11] @contextmanager
[03/03/2026, 15:14:11] def my_context():
[03/03/2026, 15:14:11]     """Simple context manager using decorator"""
[03/03/2026, 15:14:11]     print("🚀 Setup: Resource acquired")
[03/03/2026, 15:14:11]     try:
[03/03/2026, 15:14:11]         yield "Resource Data"  # This is what 'as' gets
[03/03/2026, 15:14:11]     finally:
[03/03/2026, 15:14:11]         print("🧹 Cleanup: Resource released")
[03/03/2026, 15:14:11]
[03/03/2026, 15:14:11] # Use it!
[03/03/2026, 15:14:11] with my_context() as resource:
[03/03/2026, 15:14:11]     print(f"Using {resource}")
[03/03/2026, 15:14:11]
[03/03/2026, 15:14:11] # Output:
[03/03/2026, 15:14:11] # 🚀 Setup: Resource acquired
[03/03/2026, 15:14:11] # Using Resource Data
[03/03/2026, 15:14:11] # 🧹 Cleanup: Resource released
[03/03/2026, 15:14:11] ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:14:11]
[03/03/2026, 15:14:11] The yield splits the function in two:
[03/03/2026, 15:14:11] • Before `yield`: Setup code (like __enter__)
[03/03/2026, 15:14:11] • After `yield`: Cleanup code in finally block (like __exit__)

[03/03/2026, 15:14:13]
[03/03/2026, 15:14:13] Automatically retry operations on failure:
[03/03/2026, 15:14:13]
[03/03/2026, 15:14:13]  python ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────
[03/03/2026, 15:14:13] from contextlib import contextmanager
[03/03/2026, 15:14:13] import time
[03/03/2026, 15:14:13]
[03/03/2026, 15:14:13] @contextmanager
[03/03/2026, 15:14:13] def retry(max_attempts=3, delay=1, exceptions=(Exception,)):
[03/03/2026, 15:14:13]     """
[03/03/2026, 15:14:13]     Retry operation up to max_attempts times on failure.
[03/03/2026, 15:14:13]
[03/03/2026, 15:14:13]     Usage:
[03/03/2026, 15:14:13]         with retry(max_attempts=3):
[03/03/2026, 15:14:13]             risky_operation()
[03/03/2026, 15:14:13]     """
[03/03/2026, 15:14:13]     last_exception = None
[03/03/2026, 15:14:13]     for attempt in range(max_attempts):
[03/03/2026, 15:14:13]         try:
[03/03/2026, 15:14:13]             yield  # Execute the with block
[03/03/2026, 15:14:13]             return  # Success! Exit context
[03/03/2026, 15:14:13]         except exceptions as e:
[03/03/2026, 15:14:13]             last_exception = e
[03/03/2026, 15:14:13]             if attempt < max_attempts - 1:
[03/03/2026, 15:14:13]                 print(f"Attempt {attempt + 1} failed, retrying in {delay}s...")
[03/03/2026, 15:14:13]                 time.sleep(delay)
[03/03/2026, 15:14:13]
[03/03/2026, 15:14:13]     # All attempts failed
[03/03/2026, 15:14:13]     raise last_exception
[03/03/2026, 15:14:13]
[03/03/2026, 15:14:13] # Usage
[03/03/2026, 15:14:13] def flaky_api_call():
[03/03/2026, 15:14:13]     import random
[03/03/2026, 15:14:13]     if random.random() < 0.7:  # 70% failure rate
[03/03/2026, 15:14:13]         raise ConnectionError("API timeout!")
[03/03/2026, 15:14:13]     return "Success!"
[03/03/2026, 15:14:13]
[03/03/2026, 15:14:13] print("Testing retry context manager:")
[03/03/2026, 15:14:13] try:
[03/03/2026, 15:14:13]     with retry(max_attempts=3, delay=0.5):
[03/03/2026, 15:14:13]         result = flaky_api_call()
[03/03/2026, 15:14:13]         print(f"✅ API call succeeded: {result}")
[03/03/2026, 15:14:13] except Exception as e:
[03/03/2026, 15:14:13]     print(f"❌ All attempts failed: {e}")
