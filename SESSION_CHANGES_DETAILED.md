## 🔍 What Changed and Why

### Core Philosophy Changes

1. **Centralization over Duplication (DRY)**
   - Before: Prompt logic scattered across multiple files
   - After: Single `PromptAssembler` class handles all prompts
   - Impact: Easier maintenance, consistent behavior

2. **Capability-Aware Models**
   - Before: Hard-coded assumptions about what models can do
   - After: Registry-based capability tracking
   - Impact: Better model compatibility, smarter feature detection

3. **Resilience through Fallbacks**
   - Before: Single model, fail if unavailable
   - After: Configurable fallback chains
   - Impact: More reliable execution, graceful degradation

4. **Plugin-First Architecture**
   - Before: Core features hard-coded
   - After: Plugins for new functionality
   - Impact: Easier to extend, better separation of concerns

### Integration Points

The changes integrate at these key points:

1. **`base_agent.py`** - Core agent class
   - Integrated PromptAssembler
   - Added model capability checks
   - Implemented fallback logic

2. **`agent_manager.py`** - Agent discovery/loading
   - 3-phase loading (Python → JSON → Plugin)
   - Plugin-registered agents
   - Better error handling

3. **`config.py`** - Configuration system
   - Model capability integration
   - Enhanced validation
   - Better error messages
