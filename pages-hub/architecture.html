The Watchdog
update_schedule plugin
If the machine forgets, it reminds itself
Loaded with every code-puppy session. Trust-gated, hash-verified, and impossible to silence by accident.
  • Re-enables + re-bootstraps the launchd job if it ever gets dropped
  • Self-heals its own config if something disables the plugin
  • Re-checks every 5 minutes during agent runs — throttled, never spammy
  • /update status reports schedule, sync state, Pages health

Architecture rendered 2026-08-17 against a live system. Every element on this page executes on schedule, autonomously, on the machine that generated it. Failures degrade gracefully: the pipeline rolls back, the mirrors wait, the watchdog waits five minutes and fixes it.
